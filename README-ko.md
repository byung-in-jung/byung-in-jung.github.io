## 모바일 전송 확인

기존 뷰어 원본에는 지형·건물 자료가 포함되어 있습니다. 원본 파일은 그대로 유지하고, 호스팅 서버가 HTML 응답을 Brotli 또는 gzip으로 전송하는지 배포 후 확인하세요. 모바일 네트워크 전송량은 브라우저 개발자 도구의 압축된 transferred size로, 조작 반응은 중급형 스마트폰에서 별도로 시험합니다. 호스트와 실기기 검증 전에는 모바일 로딩 속도가 검증됐다고 표시하지 않습니다.

현재 파일의 gzip 6단계 기준(2026-10-16 로컬 측정): 전국 진입 1.51 MiB → 0.47 MiB, 세종 일조 6.45 MiB → 3.15 MiB, 행복도시 9.30 MiB → 4.95 MiB, 새롬동 9.87 MiB → 5.86 MiB입니다. 전국 지도는 국가 축척에 맞춰 경계 139,475개 좌표점을 67,600개로 단순화했으며 256개 지역과 344개 다각형을 유지합니다. 모바일에서는 3D 높이를 유지하면서 베벨과 안티앨리어싱을 끄고, 지역별 경계선을 두 묶음으로 그립니다. Three.js 기하 검사는 데스크톱 베벨 포함 1,617,300개 정점·539,100개 삼각형, 모바일 베벨 제거 시 806,100개 정점·268,700개 삼각형을 확인했습니다. 같은 로컬 브라우저에서 390×844·4배 CPU 제한·1.6Mbps·150ms 지연 조건으로 완전 로드가 28.08초에서 9.48초로 줄었습니다. 모바일은 16개 지역마다 화면을 갱신해 첫 지도를 일찍 그리며, 진행 상태 문구는 첫 묶음과 64개 단위로만 갱신해 화면 읽기 알림을 줄입니다. 첫 묶음·전체 3D 완료 시점은 따로 기록하며, 이 변경의 저속 네트워크 전체 완료 시간은 아직 다시 측정하지 않았습니다. 앞선 재현 시험은 실기기나 실제 HTTP 전송량을 나타내지 않습니다. Brotli·HTTP 전송량과 실제 휴대전화 첫 표시·조작 반응은 호스팅 뒤 따로 측정합니다.
